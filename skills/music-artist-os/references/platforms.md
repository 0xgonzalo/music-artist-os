# Platform Specifications Reference

## Spotify

| Feature | Spec |
|---------|------|
| Editorial pitch | Submit 4+ weeks before release via Spotify for Artists |
| Canvas | 3–8 seconds, 9:16 vertical, looping, no text overlay, MP4 or JPEG sequence |
| Clips | In-app short video, vertical, tied to track |
| Artist Pick | Pin one item (single, playlist, event) to top of profile |
| Bio | Short: 160 chars. Long: up to 1500 chars |
| Profile photo | 2400×2400px minimum, JPEG |

## Apple Music

| Feature | Spec |
|---------|------|
| Artist bio | Editorial tone, no emojis, third person preferred |
| Artist photo | 2400×2400px minimum |
| Animated artwork | Motion artwork available via select distributors |

## Bandcamp

| Feature | Spec |
|---------|------|
| Tags | Up to 10 per release. Web search most-followed in genre |
| Bandcamp Friday | First Friday of each month — all revenue goes to artist |
| Subscriber content | Exclusive tracks, demos, stems, early access |

## TikTok

| Metric | Benchmark |
|--------|-----------|
| Completion rate | 20%+ is good. Most important metric. |
| Hook window | First 1–2 seconds determine everything |
| Optimal length | 15–30 seconds for music content |
| Best posting times | Web search current best times for genre |

## Instagram

| Format | Spec |
|--------|------|
| Reels | 9:16, up to 90 seconds, first 3 seconds critical |
| Carousel | Up to 10 slides, 1080×1350px optimal |
| Stories | 9:16, 1080×1920px, 24-hour lifespan |
| Grid | Plan in sets of 3, 6, or 9 for visual coherence |

## YouTube

| Format | Spec |
|--------|------|
| Music video | 16:9, 1920×1080 minimum, YouTube premiere recommended |
| Shorts | 9:16, under 60 seconds |
| Thumbnail | 1280×720px, high contrast, readable text |
| Description | First 2 lines visible before "show more" — front-load links |

## Email newsletters

| Metric | Healthy range (music) |
|--------|-----------------------|
| Open rate | 30–50% |
| Click rate | 3–8% |
| Unsubscribe rate | Under 0.5% per send |
| List growth | 5–10% monthly during campaigns |
